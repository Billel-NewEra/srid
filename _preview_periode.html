Preview — Sélecteur de période unifié

Année absolue · Date absolue · Plage · Raccourcis — le tout dans un seul bouton/popover. Rien n'est branché sur le serveur ici : c'est une maquette interactive.

Ce qui serait envoyé au serveur (params HTMX) :
date_filter = date_operation
date_debut  = (vide)
date_fin    = (vide)
Note : l'ancien paramètre annee disparaît — une année devient simplement une plage 01/01 → 31/12. Plus aucune contradiction possible.

À valider :

  • Le principe « 1 bouton → popover avec raccourcis + calendrier + sur quelle date ».
  • Le segment « Appliquer sur » (Dép/Vir · Réception · Échéance) placé dans le popover.
  • La liste des raccourcis proposés.
